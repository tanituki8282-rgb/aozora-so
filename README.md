# あおぞら荘の入居審査

癖のある入居希望者をドラフトし、隣人の相性で「暮らし点」を稼ぐ、戦闘なしの下宿屋パズルです。見た目は文字と絵文字だけです。点数の楽しさと、「満たされた人ほど出ていく」卒業のジレンマを確かめるための試作です。

ビルドはありません。`index.html` をブラウザで開くか、GitHub Pages に置いて遊べます。

## 遊び方

1. 表紙で種（シード）を決めて「審査をはじめる」。同じ数字なら、並ぶ順番も同じです。
2. 週の初めに、3人から1人を選ぶ。見送ると家賃が +1 され、この先の毎週の点に、倍率の外で足されます。
3. 空き部屋を押すと、置く前の予測点と内訳が出ます。納得したら「この部屋に決める」。
4. すでに住んでいる人は、週に1回だけ引越しできます（暮らし点 -2）。今週来た人の置き直しは無料です。
5. 「この配置で週末へ」で確定します。ノルマ未満だと審査の判子がひとつ。二つ溜まると、そのランは審査落ちです。
6. 3週ごとに季節が終わり、今季の満足がいちばん高い人が卒業して出ていきます。置き土産（恒久のルール）が残ります。
7. 春・夏・秋の終わりに、家訓か増築をひとつだけ選べます。冬の終わりは結果です。

1ランは春・夏・秋・冬の4季、各3週です。第1季に並ぶ人は見本で固定、順番だけ種で混ざります。第2季から、残っている人の中から種で3人出ます。

画面の「遊び方」にも、隣と空室の定義を置いてあります。

## ルールの読み方

- **隣**は上下左右だけです。ななめは隣ではありません。
- **上下が空室**は、上と下に人がいないことです。建物の外も空いています。ギタリストやピアニストの「上下が空いている」は、最上段のさらに上も空室です。
- **隣の空室**は、実在する空き部屋だけを数えます。建物の外は数えません。
- **周囲**は、ななめを含む8方向にいる人です。受験生の静けさは、ななめの騒音でも崩れます。
- **角・辺・中**は最初の3×3に固定です。増築しても角は角のままです。増築マスは「増」で、角にはなりません。
- **北が上**です。料理研究家の煙は、画面で上にいる人へ届きます。
- 誰でも **暮らしているだけで +1**。これは住人の癖とは別に付きます。
- 個人点は `(在室と加算の癖) × (1 + 倍率の癖)`。受験生の「倍率+0.5」は、静かなときの個人点を 1.5 倍します。
- 暮らし点は `(個人の合計 + 家の加算) × 家の倍率 + 家賃 − 引越し`。
- 内訳には、発火した癖を「なぜその点か」が分かる文言で出します。まだ出ていない癖は、折りたたみの中です。
- **今季の満足**は、その週だけの点ではなく、今季に積もった個人点です。季節の最後の週は、予測の順位のいちばん上が旅立ちます。同点なら、先に住みはじめた人です。
- 卒業した人は、同じランには戻りません。
- 未達2回でラン終了です。倒産ではなく「審査落ち」。置き土産を見ていれば、そのブラウザの表紙に名前が残ります。

## 種と記録

表紙の種を覚えると、同じ順番でやり直せます。アドレスの `?seed=7` でも始められます。

週末ごとの内訳は記録に残ります。結果画面の「記録をコピー」、または「バランス用の記録」から JSON を取り出せます。途中保存はありません。

置き土産の記憶は、そのブラウザの `localStorage`（`aozora-codex-v1`）だけです。

## データの足し方

住人は `js/data/tenants.js`、家訓・置き土産・増築・ノルマは `js/data/world.js` です。評価のコードは `js/systems/evaluator.js` で、条件の種類はデータの `query.kind` です。

新しい住人は、配列にオブジェクトを足すだけで並びます。例:

```javascript
{
  id: 'poet',
  name: '季節の詩人',
  icon: '✒️',
  tags: ['静か', '穏やか'],
  quirk: '角の風でないと、一行もおりない。',
  souvenirId: 'corner-gift',
  souvenirNote: '短冊を、窓辺に残していく。',
  rules: [
    {
      id: 'poet-corner',
      text: '角部屋 +2',
      query: { kind: 'isCorner' },
      cmp: '==',
      threshold: 1,
      op: 'add',
      value: 2,
      scale: 'once',
      about: []
    }
  ]
}
```

`op` は `add`（点数）か `mulBonus`（個人倍率への加算。0.5 なら ×1.5）。`scale` が `per` のときは、数えた人数をかけます。`about: ['騒音']` を付けた減点だけ、静音リフォームと防音壁がやわらげます。

使える `query.kind`:

`adjacentTag` / `aroundTag` / `verticalTag` / `houseTag` / `adjacentEmpty` / `verticalEmpty` / `aboveOccupied` / `houseCount` / `isCorner` / `isCenter` / `isExtra` / `always`

確認:

```bash
node js/systems/selfcheck.js
node js/systems/selfcheck.js --sim
```

`--sim` は、予測を見て置く人・引越しまで総当たりする人・部屋を見ない人、の三通りで30種を流し、週ごとの点を出します。

## ファイル

- `index.html` … 入口。モジュールもバンドラも使いません。
- `css/style.css` … 見た目。
- `js/data/` … 住人と荘のルール。
- `js/systems/` … 乱数、盤面、評価、1ランの進行。
- `js/ui/` … 画面。
- `js/main.js` … 起動。

画面はシステムとデータを知り、点数の意味は評価器にだけ置いています。

## GitHub Pages

このリポジトリのルートが、そのまま公開物です。

1. GitHub のリポジトリで **Settings** → **Pages**。
2. **Build and deployment** の Source を **Deploy from a branch**。
3. Branch を `main`、フォルダを **`/ (root)`** にして保存。
4. 表示された URL を開く。反映には少し時間がかかることがあります。

`docs/` フォルダは使っていません。Pages のフォルダを `/docs` にすると、この試作は配信されません。

Jekyll にファイルを隠されないよう、`.nojekyll` を置いてあります。

ローカルで確かめるときは、リポジトリのルートで次でも開けます。

```bash
python3 -m http.server 8000
```

ブラウザで `http://127.0.0.1:8000/` を開いてください。`index.html` をファイルとして直接開いても動きます。
